# Определение авторства изображений, музыки и стихотворений
Этот проект позволяет автоматически определять автора произведений по трём категориям:

Изображения (картины, рисунки), музыка (аудиофайлы), текст (стихотворения).
Использует нейронные сети и ML-модели для анализа и классификации. Включает веб-интерфейс для удобного взаимодействия.


# Установка и настройка
## 1. Требования
* Python 3.8+
* Предобученные ML-модели:
  * Для музыки: .h5 файл и artist20-temp.joblib.pkl (указаны в config.json)
  * Для изображений и текста: модели должны быть реализованы и сохранены в соответствующих модулях

## 2. Установка
### Клонируйте репозиторий
git clone https://github.com/Paulsob/NeuralNetwork_coursework
cd author-detector

### Создайте виртуальное окружение
python -m venv venv
#### Linux/Mac
source venv/bin/activate  # Linux/Mac
#### Или для Windows: 
venv\Scripts\activate

## Установите зависимости
pip install -r requirements.txt

## 3. Запуск сервера
* cd server
* python app.py
* Сервер запустится на http://localhost:5000.

## 4. Использование
* Откройте интерфейс
* Перейдите в браузере по адресу:
* http://localhost:5000
* Выберите тип анализа
  * Изображения: Загрузите файл (JPG, PNG) и нажмите «Предсказать»
  * Музыка: Загрузите аудиофайл (MP3, WAV)
  * Текст:
    * Введите стихотворение в текстовое поле ИЛИ
    * Загрузите файл (.txt или .docx)
  * Получите результат
  * Система покажет:
    * Вероятного автора
    * Уровень уверенности

## 5. Технические детали
* Backend (Flask)
  * Эндпоинт: POST /predict
  * Поддерживаемые форматы:
    * Изображения: JPG, PNG
    * Аудио: WAV
    * Текст: .txt, .docx или печатный текст в соотвествующем поле
* Frontend
  * Адаптивный дизайн
  * Независимая загрузка файлов для каждого типа анализа
  * Отображение имени выбранного файла и результата
* Возможные проблемы и решения
  * ModuleNotFoundError
    * Убедитесь, что все зависимости установлены: pip install -r requirements.txt
  * Ошибка загрузки моделей
    * Проверьте пути в config.json и наличие файлов
  * CORS errors
    * Сервер уже настроен с flask_cors — проблема может быть в неправильном URL клиента
  * Отсутствует поддержка .docx
    * Установите python-docx: pip install python-docx
  * Долгая загрузка изображений
    * Убедитесь, что модуль models/images.py реализует метод predict()

## 6. Советы
* Для лучшей точности используйте оригинальные произведения без сжатия.
* Музыкальная модель обучена на фрагментах 30 секунд — более короткие файлы могут давать неточные результаты.
* Уровень уверенности возвращается в диапазоне [0, 1] и отображается с тремя знаками после запятой, как вы предпочитаете.
